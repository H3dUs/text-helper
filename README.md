# Text Helper

Расширение для Visual Studio Code с набором полезных команд для работы с текстом.

**Автор:** Дементьев Дмитрий Алексеевич, группа M3112

Лабораторная работа №3 по дисциплине «Инструментальные средства разработки программного обеспечения».

## Возможности

| Возможность | Как вызвать | Описание |
|---|---|---|
| Счётчик слов в строке состояния | Работает автоматически | Внизу окна справа отображается количество слов в выделенном фрагменте, а если ничего не выделено — во всём документе. Обновляется при наборе текста и смене выделения. |
| Статистика текста | Палитра команд → `Text Helper: Статистика текста` или клик по счётчику в строке состояния | Показывает уведомление с количеством строк, слов и символов в выделении или во всём документе. |
| Вставка даты и времени | `Ctrl+Alt+D` (`Cmd+Alt+D` на macOS) или палитра команд → `Text Helper: Вставить дату и время` | Вставляет текущие дату и время (формат `ДД.ММ.ГГГГ, ЧЧ:ММ:СС`) на место курсора. Поддерживает несколько курсоров. |
| Перевод в ВЕРХНИЙ регистр | Контекстное меню редактора или палитра команд → `Text Helper: В ВЕРХНИЙ регистр` | Переводит выделенный текст в верхний регистр. |
| Перевод в нижний регистр | Контекстное меню редактора или палитра команд → `Text Helper: в нижний регистр` | Переводит выделенный текст в нижний регистр. |
| Сортировка строк | Контекстное меню редактора или палитра команд → `Text Helper: Отсортировать строки` | Сортирует выделенные строки по алфавиту (с учётом русского языка). |

Команды смены регистра и сортировки появляются в контекстном меню (правый клик), только когда в редакторе есть выделение. Все команды работают с несколькими выделениями одновременно.

## Настройки

| Параметр | По умолчанию | Описание |
|---|---|---|
| `textHelper.showStatusBar` | `true` | Показывать ли счётчик слов в строке состояния |

Изменить: `File → Preferences → Settings`, найти «Text Helper».

## Установка

### Из файла .vsix
1. Скачать файл `text-helper-1.0.0.vsix` из раздела Releases.
2. В VS Code открыть панель Extensions (`Ctrl+Shift+X`) → `...` → `Install from VSIX...` и выбрать файл.

### Из исходников
```bash
git clone https://github.com/H3dUs/text-helper.git
cd text-helper
npm install
npm run compile
```
Затем открыть папку в VS Code и нажать `F5` — запустится окно Extension Development Host с подключённым расширением.

### Сборка .vsix
```bash
npm install -g @vscode/vsce
vsce package
```

## Требования
- VS Code 1.90 или новее
- Node.js 18+ (только для сборки из исходников)
